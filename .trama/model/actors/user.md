# User

La persona che usa l'app per registrare le proprie call.

## Events

### START
L'utente preme Avvia per iniziare a registrare una call.

### STOP
L'utente preme Ferma a fine call.

### RETRY_DOWNLOAD
L'utente preme Riprova dopo un download dei modelli fallito.

### RETRY_TRANSCRIPTION
L'utente preme Riprova dopo una trascrizione fallita.

### OPEN_TRANSCRIPT
L'utente preme Apri per vedere l'ultima trascrizione.

### CLOSE_WINDOW
L'utente prova a chiudere la finestra dell'app.
